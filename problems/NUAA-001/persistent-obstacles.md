# 含持续隐藏记忆的障碍轨迹如何进入双侧安全判定

[有限合同底稿](finite-contracts.md) 中，图边的障碍脚本可由有限模式合法拼接。这里考虑跨步不可重置的真实状态 z。物理端每步映射 z_{k+1}=F_k(z_k)，离散模式与合法外源输入固定为该条图路径上的同一串；F_k 允许随这些输入变动。障碍的格间几何与传感标量对步首 z 有共同可计算连续模。假设所有必需映射在参考路径一个固定邻域内可延拓，离散守卫有明确容差，或只依赖离散脚本。外系统不读取尚未固定的飞行器连续状态。以下公式使用欧氏坐标；对环面可用一致的局部提升作增量计算。

## 一条可直接检查方向的线性对偶公式

图路径给出 z̄_0,…,z̄_N，逐步残差 e_k=z̄_{k+1}−F_k(z̄_k)，以欧氏范数计。设 A_k=DF_k(z̄_k)，定义 (Lv)_k=v_{k+1}−A_k v_k。使用乘积空间逐时刻最大欧氏范数。若初始值可在加宽初态集中调整，则将 v_0 纳入未知量；若初态必须固定且 z̄_0 就是该初态，则置 v_0=0。线性方程 Lv=−e 的最坏最小修补增益为

$$C_N=\sup_{\|e\|_\infty\le1}\min_{Lv=-e}\|v\|_\infty
=\sup_{\lambda\ne0}\frac{\sum_{k=0}^{N-1}\|\lambda_k\|_2}{\|L^*\lambda\|_1}.$$

分母是端点及内点块的欧氏范数之和。自由初值时这些块依次为 −A_0^T λ_0、λ_{k−1}−A_k^T λ_k（1≤k<N）、λ_{N−1}。固定初值时删去首块。证明：L 把半径 C 的闭单位球像覆盖扰动单位球，当且仅当每个方向 λ 上的支撑函数都覆盖；有限维闭凸集分离即得公式。L 总是满射，因为把 v_0 置零即可逐步解方程。该公式不假设逐残差的最小范数解对 e 是线性映射。

也可容许一次调整固定隐藏参数 p。若其一阶导数是 B_k，则扩大算子为 (Lv)_k−B_k Δp；在包含 ‖Δp‖ 的同一最大范数下，分母只增加一个块 ‖Σ B_k^T λ_k‖。若物理上允许每一步各自修正参数，则分母会增加 Σ‖B_k^T λ_k‖。这两种合同的差别可以随时域增大。若参数量纲与位置不同，先按实际物理余量缩放各变量；参数校正后须仍在真实允许集中。

## 无跨步重置的非线性修补

假定每条待验证有限图路径的 C_N 有共同的可计算上界 C；导数在所用邻域为 M-Lipschitz。每步残差至多 η。若 r=2Cη 在延拓邻域内且 C M r≤1/2，则存在全路径一致的修补，满足 ‖v‖∞≤r，且 z̄_k+v_k 是同一模式序列下真实的逐步轨迹。初值类型按上节选择。参数版本在联合变量上采用相应的导数界。

证明。令非线性余项 R_k(v)=F_k(z̄_k+v_k)−F_k(z̄_k)−A_k v_k，则 R(0)=0 且 R 在半径 r 的球上有 Lipschitz 常数 Mr。先取一个 ‖v¹‖≤Cη 的解使 Lv¹=−e。从 v^j 出发，取一个最小范数增量 w 使 Lw=R(v^j)−R(v^{j−1})，其中 v⁰=0；再令 v^{j+1}=v^j+w。每份增量范数至多前份的一半，总半径至多 r。完备性与连续性给出极限 Lv=−e+R(v)，即所求。本证明绕过了将最小修补错当成线性右逆的步骤。若初态必须固定，不能用自由初值版 C 替代，否则不稳定方向可能凭借实际不允许的初态变动得到虚假的界。

可实施的充分条件之一是可计算的不变稳定/不稳定分裂，前向稳定与反向不稳定传播（含投影）均有 Kρ^j 的界，0<ρ<1，初态可调整。在稳定子空间从零初值向前累加，在不稳定子空间从零终值向后累加＝每项残差分别在两方向传播；每个时刻的范数至多 2K/(1−ρ) 倍最大残差。此构造只使用真实外系统的初态余量。若初态锁死而全部方向前向收缩，则只需前向累加。经典影随理论已研究伪轨道与精确轨道的关系。[Pilyugin 与 Tikhomirov](https://arxiv.org/abs/1010.3688)

接入物理图时，图到真实问题的安全充分性仍由向外网格包围保证，不需要影随。反方向取图上假设的失败前缀，先按本引理修补整条障碍轨迹，再按刚体拼接修补飞机，并用模连续界支付传感、格间净空与参考误差的变化。对于每架机观察序列相同，因果控制器会产生同一组模拟命令。只要所有改变量都被较难实例的余量接纳，该失败便与其鲁棒安全矛盾。用未来步帮助选择一个初始障碍状态在这里是合法的：这在证明存在一条与假设失败相容的物理环境轨迹，控制器仍只读取本地历史。若物理环境规定已知精确初态，就必须使用固定初态版本。只靠逐个有限路径计算 C_N 并观察其尚小，并不能认证对所有路径的统一上界。

## 匀速障碍上可以精确计算的反例

设一维障碍真轨迹为 α+β k，α、β 可在全体实数中自由选择。图节点形成伪轨迹 y_0,…,y_N，已减去共同名义趋势，|y_{k+1}−y_k|≤η。定义 N≥1 拍上的最坏最佳位置修补误差为

$$E_N=\sup_y\min_{\alpha,\beta}\max_{0\le k\le N}|y_k-\alpha-\beta k|
=\eta\,\frac{\lfloor N^2/4\rfloor}{N}.$$

证明。最小误差是到仿射序列子空间的最大范数距离，其对偶为 max Σ μ_k y_k，约束 Σ μ_k=Σ kμ_k=0、Σ|μ_k|≤1。可把 μ 写为正、负两个非负向量之差，并补松弛量。归一化预算加两个矩约束共三条等式，故有极值基本解至多三个非零变量。非零有效解必在三个不同时刻 a<b<c 取支撑，权重按比例为 c−b、−(c−a)、b−a，总绝对值归一为 1。因 y 是 η-Lipschitz，其配对绝对值至多 η(b−a)(c−b)/(c−a)。取在 b 处改换增量符号的折线即取等。对整数间距 l=b−a、s=c−b，上式 ls/(l+s) 对二者均递增；固定和 N 时在二者相差至多一处最大。N=1 时两点可精确拟合。证毕。

这一常数给出了量级和尖锐系数：就算允许事后重选初始位置和同一未知速度，也无法用与 N 无关的 O(η) 空间余量吸收每步独立的位置取整。有限初值或速度区间只可能令误差更大。这是逐步残差模型的反例，并不意味着每种量化算法都能产生全部这样的伪轨迹，也不证明匀速障碍的安全判定不可行。实际算法若利用同一个世界参数解释整个观测史，仍可能成功。

计算复核取 η=1，逐一枚举 N=1,…,9 的所有增量顶点 {−1,1}^N，共 1022 个序列。每个序列独立用线性规划最小化 t，约束 −t≤y_k−α−βk≤t。各 N 的最坏解与公式的最大绝对差为 2.23×10⁻¹⁶ 以内。该核对没有使用上面的三点对偶表达式。[在周期运动上保留共享参数的另一种精确计算](shared-phase.md)
