# 状态包迟到时的精确终端容差与最少采样次数

取有限时域 [0,H]，受控系统 ẋ=Fx+Bu+Ew，初态已知，U、W 为紧凸零中心对称盒，风可随时在 W 内任意取值。目标误差是 |lᵀx(H)−lᵀexp(FH)x₀−σX|，X≥0，方向 σ∈{−1,1} 独立于风，在时刻 r 才公开。执行端在收包间没有其它透露风的信息。每个状态包给出精确的历史状态和时间戳；可以乱序、缺失、成批交付。先固定有限交付日程，随后允许从外生合同中未知地选择日程。控制端知道自己全部命令。

记 Φ(t)=exp(Ft)，k(t)=h_U(BᵀΦ(H−t)ᵀl)，d(t)=h_W(EᵀΦ(H−t)ᵀl)，其中 h 是支撑函数。定义 K(t)=∫ₜᴴk，D(t)=∫ₜᴴd。t 时刻**严格以前**已交付的最新时间戳记为 a(t−)，若无则取 0。判据如下：

$$R_* = \max\left(0,\sup_{0≤t≤H}\{D(a(t-))+X\mathbf1_{t≤r}-K(t)\}\right).$$

**定理。** 最小可保证投影误差恰为 R_*，允许任意因果控制也不能改善。对已给外生交付日程族，如果任一日程可与任意风史及类型组合，则最坏最优值为各日程 R_* 的上确界，执行策略无需预知下一次交付。若发包时机依赖真实状态、内容或类型，静默可能携带信息，不能无条件套用此下界。

**证明。** 时间戳 s 的包到达时，从 lᵀΦ(H−s)x(s) 中减去已知初态项及 [0,s] 命令的终端投影，就精确得到风在 [0,s] 对最终投影的有符号贡献。过期包无需参与构造。每次最新时间戳由 a 推进到 s 时，新增贡献绝对值至多 ∫ₐˢd。方向公布时另加 −σX。在 H 将最终仍未证实的风视作一个绝对值至多 D(a) 的末端增量；这只是计算实际终值，不授予任何提前信息。于是按事件次序逐次把已知有符号贡献加到 z（包括累计命令投影，初始为零）。两次事件间，若 z>0 选择终端投影率为 −k 的命令，若 z<0 取 +k，到零就停。盒对称保证可实现，执行不需知道风。每个开放时间段使 |z| 从 b 至多降为 (b−∫k)_+；每批事件使它至多增加该批的总绝对幅。由归纳，最终 |z| 不超过所有事件后缀的总幅度减该后缀剩余控制容量的最大非负值。后缀从时刻 t 本批开始时总幅正是 D(a(t−))+X·1_{t≤r}。在无事件区间后缀幅度恒定，K 递减，故只需检查各交付、方向公布和 H，连同 0 即可。

反向，固定任意切点 t。构造两个世界：最新已交付时间戳以前的风相同，之后对 l 的终端影响分别逐时取相反支撑点。若方向尚未公布，同时选相反的 σ 使目标差和风差相加；若已公布，保持同一 σ。两个世界 t 前交付的**完整状态包**相同，不仅其投影相同，因为相应时戳以前风、初态和因果命令都相同。尽管可能已有尚未交付的不同真实运动，执行端看不到它。t 后全部命令最多将两世界的终端误差差值抵消 2K(t)，所以至少一个世界的绝对误差达到括号内的值。对 t 取上确界匹配。逐时支撑点在盒中按各分量符号即可选取。相同上界策略适用于每一外生日程，证明日程族结论。这里的后缀递推与确定性排队积压有相同代数结构；控制问题的匹配下界来自真正不可区分的全状态回放。[Le Boudec 与 Thiran 的网络演算](https://leboudec.github.io/netcal/)

## 给定允许误差时，最少需要几次状态采样？

先取 X=0，单包固定耗时 ℓ≥0，可在连续时间选采样时刻；采样次数指实际交付 H 前的状态测量。最新时间戳 a 已送达，初始 a=0。若 D(a)≤δ，则无需再采样。否则下一包的交付时刻必须不晚于

$$ T(a)=\max\{t\in[0,H]:K(t)≥D(a)−δ\}. $$

若集合空则不可行。在最晚容许时刻 T(a) 交付，采样时刻为 T(a)−ℓ。若该新戳不大于 a，任何允许的下一包均不会带来新信息，故无有限方案。否则用新戳替换 a 重复，达到 D(a)≤δ 时结束。固定时延可流水发送；该算法是离线日程设计，采样可以发生在前一包交付之前。对给定预算 N 最多迭代 N 步即可决定是否足够；不对临界容差承诺无预算迭代一定终止。

最优性：对任意可行日程，其首个推进时间戳的新包不能晚于 T(0)，因为交付瞬间还没有时间把新信息转为位移。贪心新时间戳至少与它相同。T(a) 随 a 单调不减；逐包归纳得贪心的第 j 个新戳始终不早于竞争日程的第 j 个。若竞争者 N 步能把末端未观测部分压至 δ，贪心至多 N 步也达到。每个交付切点满足容差界，末端停止条件也恰当，故确实可行。最短采样间隔、发送冲突或时间戳量化若存在，必须另计。

## 真实机动中的应用边界

对水平姿态的一阶电机竖直机动，取状态为高度、速度、实际净推力加速度，力系数已按质量归一，命令幅值 A，风幅值 b，电机速率 ν。终端高度方向的核 k(t)=A[(H−t)−(1−exp(−ν(H−t)))/ν]，d(t)=b(H−t)。全部结论在任意 H 下精确，并不需要收到连续风速。包中须包含所需状态或能精确重建该终端投影的统计量；仅报告高度一般不足。对于三维非线性飞行和多次沿程避碰，仅在某方向有合法的上下包围或可分离的线性子系统时可据此签发相应证书。单个终端投影达标本身不能保证整段安全、完整悬停交接或分布式稳定。
## 同时要求位置、速度及实际电机状态时的精确递推

上面的标量闭式不能逐坐标拼接，但可直接从同一时间戳合同导出联合算法。固定日程及终端线性映射 L（可取恒等，或取机间相对状态），定义两个对称紧凸集

$$C_{ab}=\left\{\int_a^b LΦ(H-t)Bu(t)dt:u(t)∈U\right\},\quad
Q_{ab}=\left\{\int_a^b LΦ(H-t)Ew(t)dt:w(t)∈W\right\}.$$

按所有交付、方向公布和 H 排序。从已知终点漂移 LΦ(H)x₀ 出发，维护一个向量 z，等于此漂移、全部已执行命令终端贡献、以及最新已交付戳前的风终端贡献之和。新戳从 a 进至 b 时，真实包精确给出向量增量 q∈Q_ab，且不同新戳区间可独立选取。任意控制间隔 [i,j] 允许 z 增加任一 c∈C_ij。给定终端允许集合 T_σ，倒序使用以下三条规则：

* 经过没有新信息的控制间隔，将允许集 V 替为 V+(−C_ij)。进入位置 z 可行恰因存在一个可实现的 c 使 z+c∈V。
* 逆过新包，将 V 替为 V⊖Q_ab，即所有 z+Q_ab⊆V 的 z。终端仍未观测的风使用相同规则，处理后已无后续命令。过期包无须分支。
* 逆过方向公布时刻，把两种已知方向的允许集相交。若同刻既交付新包又公布方向，交集与同一集合的腐蚀可交换；这一步没有瞬时执行器位移。

初始漂移属于所得集合即为充要条件。反向归纳证明：在两个交付之间，任何命令波形只依赖以往已知量；在下一包中所有可能 q 都可由一个合法风段实现，即便该风段在物理时间上与过往控制重叠，因为其对应状态尚未被任何更新戳观察。已交付状态的其它分量不会制约未来独立风段，故没有丢失对终端任务有用的因果信息。充分方向在每个 z 选择一个使后继合法的 c 和实现波形；在闭凸目标及紧凸输入的情形，可在可行波形中依次取最小 L² 范数（有限时长上的闭凸集合），得到唯一的选择。固定交付日程是此联合策略的条件，未知日程不能先选择与未来日程有关的动作。沿程禁入区并未由终端投影自动保证。

**为什么所有方向的单独最优值都可能误报。** 取终端三角形 T=conv{(0,0),(2,0),(0,2)}，允许在看不到末批扰动前选一个平移量 z∈[−3,3]²。末批扰动 Q=(T−T)/2 为六边形，可由三个独立盒分量分别乘 (1,0)/2、(0,1)/2、(1,−1)/2 产生。任一方向上，Q 和 T 的投影宽度完全相等，针对该方向单独平移可成功。然而若 z+Q⊆T，则 x、y 两坐标的最小值约束要求 z₁,z₂≥1，而 x+y 的最大值要求 z₁+z₂≤1，矛盾。联合递推给出 T⊖Q 为空，因而是严格不可行。这个例子是线性终端任务的反例；它解释了完整悬停交接必须让全部状态分量共用一套机动。
