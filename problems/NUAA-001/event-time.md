# 实际事件时刻与算法网格的接口（内部工作材料）

逐个相邻网络事件拼接轨迹需要代价 $\varepsilon_p/h^2$；即使每架机自身都有最小发包间隔，两架机各发一次也能让全局相邻事件间隔任意小。所以不能把各机的无 Zeno 性直接作为刚体拼接引理的全局步长下界。可分开固定的动力学修补窗口 $h$ 与用于时间戳的细格 $\Delta$，每个修补窗口允许许多网络事件。

**电机对任意快速指令的平均误差。** 对 $\dot f=D(c-f)$，标量命令在 $[0,1]$，在各时间格上取 $c$ 的均值为 $\bar c$。若两条电机轨迹从相同初态开始，则

$$\sup_{t\ge0}|f(t)-\bar f(t)|\le D\Delta/2.$$

令 $P(t)=\int_0^t(c-\bar c)$。完整格贡献为零，在均值为 $p$、长度 $\Delta$ 的一格内，任一前缀正、负差的绝对值最多为 $\Delta p(1-p)$：正极端由先取 1 后取 0 达到，负极端次序相反。故 $|P|\le\Delta/4$。对卷积核作分部积分得
$f-\bar f=DP(t)-D^2\int_0^t e^{-D(t-s)}P(s)\,ds$，即证。均值再量化到半径 $\nu$ 的命令网只增加 $\nu$，因为电机的静态增益为 1。故仅为匹配机械运动，便可以跨任意多格统一抑制指令振荡。**在线使用的限制**是所取均值必须能从本机当前信息确定；直接把未见过的连续反馈实现作时间平均会成为非因果策略。

**因果实现的一种情况。** 实际机载测量为连续状态的 Lipschitz 函数，物理状态速度有界；较难问题容许测量在每时刻有附加幅值余量 $\eta_y>0$，而且允许不连续噪声。向虚拟控制器提供最近网格测量的代表值并保持到下一格。如果实际名义无噪读数的最大变化率为 $L_y$、代表值量化误差为 $\nu_y$、刚体拼接产生的读数误差为 $E_y$，则这种虚拟测量相对于扩大后的真实物理轨迹新增的必要容差至多 $L_y\Delta+\nu_y+E_y$；不能假定原测量噪声本身 Lipschitz。此估计用的是采样瞬间真值加原噪声界，以及之后无噪读数的连续性。选择尺寸使总和小于 $\eta_y$。若虚拟系统在格内没有外来消息，保持的读数、时钟及当前私有历史决定其整格行为。在控制器良定、可以离线展开为规则的意义下，均值是当前历史的函数；若直接运行的是任意黑箱控制代码，则还要对格内仿真/积分的可计算性和时间预算另行证明。图策略有限时，可以用合成得到的有限表取代在线求积。

**消息延迟的双向核算。** 时间向上取整到格点。假设每个发送端的最小间隔是整数倍格宽且至少为一格，每条链路的递送遵循给定有界延迟区间，传感或包的精确亚格时间不作为额外载荷。真实使用格点发送时，把格内到达的包缓冲到右端格点才交给图控制器，可增加不到一格的递送延迟。反向模拟时，虚拟控制器在格内产生的包到格末才实际发送；把图中观测到的递送时刻原样交给虚拟控制器，则其经历的延迟比图中延迟多至一格。由此用外扩两格的最坏延迟容差可包含两个方向的向上取整；在只取整送达且发送本已在格点的方向无需两格。最小发送间隔 $m\Delta$ 保持，因为 $\lceil(s+m\Delta)/\Delta\rceil-\lceil s/\Delta\rceil=m$。同格多个来源包的顺序须作为字母枚举，且虚拟控制器读取这一顺序；要求同源多包次序不明时则须提供序列号。为避免同一格点处的「先收还是先发」代数环，可约定先交付既有包、再决策，且一切新发包最早在下一拍交付；若真实通路允许零时延连锁反应，则需要额外外扩一格或单独证明某种微步语义，不能直接沿用两格计数。

**反例检查。** 若发送时刻是无误差实数、载荷却计作一比特，则在一固定窗口内单次发送时刻已可编码任意多离散消息（选不同有理时刻即可），不能据载荷带宽推出有限消息字母表。另一方面，硬阈值越过时输出发生瞬时跳变，例如「没有探测到障碍」变为「目标在范围内」。仅令 $\Delta$ 小不能使这两种符号的数值距离小；应把可能的接触/首次探测时间窗及邻近符号纳入传感合同，或给出可验证的触发鲁棒性证明。固定跨机公共刷新也不会由向上取整自动产生。

这些局部界支持把受扰刚体的长期拼接与有余量的时间协议结合，但对任意异步环境并未建立精确的双向抽象；尤其还缺少不可预知新障碍事件的相容后继、真正的网络预算和稳定性合同的同时闭合。
