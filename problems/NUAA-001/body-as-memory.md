# 将机体姿态当作私有记忆时，动力学允许保存多少信息

给私有控制器的记忆建立下界时，飞机可以通过自己的运动留下信息，并在下一次机动前用传感器读出。如果忽略这条通路，纯消息计数可能产生错误的不可能性结论。下面把这条通路的容量写成真实可达集的问题。

## 单次写入、一次读出的容量

在一段任务交接中，写端暂时获知一个离散标签，可选择指令使飞机从已知初态飞行 h 秒。标签随后不再由外部提供。读端须从结束时的测量和允许保留的数字记忆决定下一项机动。除这些明列通路之外，不得再免费读到旧命令缓冲、真实标签或不可区分情景的其它标志。要求每个可能被事后要求的标签位都能无误读出。这种“所有位均可能被检验”的任务，不要求在同一飞行中把每个位都发送出去。

设名义无扰端点可读量的可达集为 R_h，各分量的读数误差为独立闭区间 [−δ_i,δ_i]，δ_i>0。**在无过程扰动的单次合同中，物理状态可传递的最大标签数恰为 R_h 中能选出的最多点数，使任意两点在至少一个坐标相差严格大于 2δ_i。** 必要性：如两点在每一维都相差至多 2δ_i，则相应误差盒有共同读数，事后选一个不同的标签位即无法区分。充分性：预存每个码点的一条实现轨迹，按标签写入，按不相交的测量盒译码。若还有过程扰动，必要性可固定无风支路；充分性则必须使每个码字的**所有真实端点读数**与其它码字读数不交。若有已证明的逐维端点偏差 σ_i，可在名义编码的充分条件中用 δ_i+σ_i 替换 δ_i。机体间、障碍间的格间净空要求都必须在 R_h 的生成轨迹上满足；仅用无障碍可达集给出的通用界是上界。

标量连续输出尤其简单：若所有允许波形构成紧连通集、轨迹与输出连续，则 R_h 是完整闭区间，宽度 W_h。容量恰为 max(1,⌈W_h/(2δ)⌉)。若 W_h/(2δ) 恰为整数，两个误差盒在端点相接也会导致混淆，不能多算一个码字。非凸障碍有时会使安全可达集断开，此时区间宽度只给上界，不能用它自动证明足够多的码点均可到达。

## 从水平悬停出发的四旋翼容量

取四个受限电机的标准刚体，悬停命令在盒内部、控制分配满秩，整段不出现障碍或处在净空大于全部格间位移的悬停邻域。用真实状态局部坐标 (电机推力偏差、角速度、旋转对数、竖直速度、竖直位置、水平速度、水平位置)；局部读数误差按这些坐标给定。由 [全动力学局部可达性](three-dimensional-tracking.md)，小 h 时存在与 h 无关的 c,C>0，使以第 l 个坐标半径 c h^{w_l} 构成的闭盒包含于 R_h，R_h 又包含于半径 C h^{w_l} 的外盒。各组 w_l 分别为 (1,2,3,2,3,4,5)，维数为 (4,3,3,1,1,2,2)。

因此真实物理容量 N(h,δ) 有双侧界

$$\prod_l\max(1,\lceil c h^{w_l}/δ_l\rceil)\;≤\;N(h,δ)\;≤\;
\prod_l\max(1,\lceil C h^{w_l}/δ_l\rceil).$$

下界在内盒的每维放严格可分辨的等距点，再取直积；[局部可达性证明](three-dimensional-tracking.md) 的有限个命令参数能构造这些码点。上界把外盒逐坐标划成直径不超过 2δ_l 的单元，每个单元至多容纳一个可区分码点。于是同时让 h 与测量分辨率变化，N 的量级为 ∏(1+h^{w_l}/δ_l)，常数只依赖模型和固定维数。若每个被读坐标都处于高分辨率区间，全部 16 维的可分辨点数量级为 h^42/∏δ_l；42 是四条可控链的坐标权重之和。若 δ_l 固定并让 h 趋零，容量反而最终恰为一，不能把高分辨率表达式外推到这一情形。

只读水平投影 n·p 时可给主系数。若四维命令盒各通道宽度为 A_l，L 为 [短窗展开](information-dual.md) 的水平线性映射（已含 g/24），则 W_h=h⁵Σ_l A_l |(nᵀL)_l|/5+O(h⁶)。正负极限分别用盒端点的常值命令取得，余项对所有指令统一。这个公式把电机带宽、惯量以及能否在失联期间用微小位移区分两项后续机动直接联系起来。

## 通信、私有记忆和动作留下的物理痕迹必须一起计算

设先后出现 n 个任意预警比特，要求之后对任何所问的单个位给出安全的两选一机动。索引在写入时未知，所有索引都可能；相反的答案对应没有共同安全后续动作的两个世界。在作出选择前，写端已经失去原始输入，只可使用本地持久记忆（最多 M 状态）、早期可供后来解码的发送记录（至多 C 种）和上述一次物理读数，且后续没有其它区分这些字的机会。则

$$2^n≤M C N(h,δ)$$

是永久安全的一个必要条件，即使控制器可选任意三维飞行动作。对每个字固定一种无风实现和合法的存储噪声代表，按数字记忆及可用消息记录分组。组内任意两个字若有相同后续物理读数的可能，就选它们不同的某一位作为查询；解码端可得到相同历史却须采取不同动作。于是每组至多 N 个字。对有限精度矩形寄存器，M 可取 [私有存储等价式](private-registers.md) 的精确值。C 必须包含可观察的静默、到达顺序及时间信息；若发送时刻无限精确且免费，不能只数载荷字节。

当整字在写入动作开始前就一次可用，数字记忆、可用码字、可达物理码点可独立选择，且截止时相同解码端能访问三者时，上式也充分：将每个字注入三者的直积并按索引查位。若输入按位陆续抵达而执行器必须边接收边写，最终可达点数不保证这些点能由一棵满足前缀相同则指令相同的在线策略树到达，此时不能宣称乘积上界可达。同样，若不同飞机只看到各自私有的其中一项，还要检验分布式译码的相容性。这个下界直接针对信息不足导致的避碰失败，没有把“辨认标签”强加给原本可以安全共用同一机动的避碰任务。

## 对流式预警，标量运动通路的精确因果判据

下面求出一个能完整处理前缀限制的结论。第 j 个标记在时刻 t_j 到达，取 q_j≥2 种值；t₁<…<t_n<t_{n+1}=H。在写入期间发出的命令可使用全部已到达标记，读出时只能看一维运动输出；写入控制器若还被限制不能暂存早先标记，本定理的充分性需要额外验证。假设标量终端输出为已知常数加各时段的动作贡献之和。每段贡献可独立实现某一紧区间中的任意数，去除与标记无关的区间中点后记为 [−r_j,r_j]。这包括受限电机输入到某个终端投影的线性卷积；只对积分贡献作独立选择，实际电机状态没有在段间复位。记 P_j=∏_{k=j}^n q_k、R_j=Σ_{k=j}^n r_k。

**定理。** 在所有因果写入规则中，全部不同标记串之间可取得的最大最小终端间距恰为

$$2g_*,\qquad g_*=\min_{1≤j≤n}\frac{R_j}{P_j-1}.$$

因此有界闭读数误差 δ 下，全字及任意事后所问的位可零差错取回，当且仅当 δ<g_*。若有独立、写入端不可观察且实际可以填满区间 [−σ,σ] 的加性终端偏差，公式中改用 δ+σ。若物理偏差只有上界、不能取满，则这种替换仅用于充分性。

证明上界。固定前 j−1 项的任意共同取值。该组的 P_j 个物理输出共享前面所有已做决定，其值落在长至多 2R_j 的同一区间，于是最小间距不超过 2R_j/(P_j−1)。取所有 j 的最小值。尤其最后时刻才揭示的标记不能使用较早已过去的机动时间。

证明可达。令第 j 个标记的“满幅需求”为 d_j=(q_j−1)P_{j+1}g_*，约定 P_{n+1}=1。由于 Σ_{k=j}^n d_k=(P_j−1)g_*≤R_j，能在时段 k≥j 中分配非负系数 a_jk，使 Σ_{k≥j}a_jk=d_j、Σ_{j≤k}a_jk≤r_k。具体做法是从最后一个标记倒序起，将其需求放进不早于其到达的尚未占用容量；每步够用正是上述后缀不等式。若标记取数字 b_j∈{0,…,q_j−1}，第 k 段选择其贡献为

$$\sum_{j≤k}a_{jk}\big[2b_j/(q_j−1)-1\big].$$

该值仅依赖已到达标记，且不超执行器容量。终端值为 2g_*Σ_j b_j P_{j+1} 加公共偏置。混合进制整数恰好取到 0,…,P₁−1，故达到上界。这里控制同时为先前标记继续累积机动，并为尚未揭示的标记留出后段余量；逐位一律等分每个时段通常达不到最优间距。

**应用于真实短窗四旋翼。** 从水平悬停开始，以 n₀·p_xy 为传感器读出方向，设 c=Σ_l A_l |(n₀ᵀL)_l|/10，L 和 A_l 的意义同上。对真实时长 h=t_{n+1}，线性首项的半区间容量是

$$r_j=c\big[(h-t_j)^5-(h-t_{j+1})^5\big],\quad
g_*=c\min_j\frac{(h-t_j)^5}{P_j-1}.$$

每段只需在盒端点的正负方向极值命令之间作同一比例的凸插值，即可取得分配的积分。由 [全姿态显式余项](information-dual.md) 的单轨误差 B(h)，真实最优最小间距落于 [max(0,2g_*−2B(h)),2g_*+2B(h)]。原因是对任何一棵非预见指令树，各叶的真值与首项均相差 ≤B(h)，于是任意两叶的距离及其最小值最多改变 2B(h)；反向用上述同一棵混合进制树即可。此上界覆盖四路电机可任意倾转的指令，并非只比较一份预设动作库。无外矩时，不可测惯性系水平风沿读出轴产生的独立位移区间若为 [−d h²/2,d h²/2]，则零差错充分条件为 δ+d h²/2<g_*−B(h)，而 δ+d h²/2≥g_*+B(h) 排除任何写入树。此处预警码只能经终端位置传给下一决策，若读端还能读角速度、旧消息或整个飞行轨迹，则信息量会变化。

例：两位二值预警，第一个从起飞即知，第二个在 h/2 才知道。按单次可达区间宽度估计得到的理想半间距为 ch⁵/3；实际可达到的首项只有 ch⁵/32，后半程剩余机动时间成了瓶颈。相反，若第二位足够早到达使 (h−t₂)^5≥h⁵/3，就能达到 ch⁵/3。这给出一个具体的路径规划与通信时限条件，而不仅是计数码点。
