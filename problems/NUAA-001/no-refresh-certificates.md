# 不依赖公共刷新的双侧证书

沿用 [有限合同底稿](finite-contracts.md) 已给出双向轨迹误差界的模型与参数族。对任何一次指定的抽象精度，隐藏节点集 Q、每机动作和观察字母表均有限。每条边给出动作组、下一节点、各机下一观察和格间失败标志。网络、障碍脚本、参考与上一参考、执行器可行性、稳定性比较涉及的历史量都须先进入节点或边。初始观察可经一个强制空动作生成。安全语义是任何有限前缀均不出现失败边。这里取消每隔 L 步公共刷新全部历史的假设，不约束私有历史长度。

## 负证书与正证书有不同的完备范围

在任意这样的有限图上，下面两件事同时成立。

1. 不存在永久安全的因果策略，当且仅当某一有限深度没有任何安全的分布式策略树。可枚举深度判输。
2. 存在可由有限本地记忆实现的永久安全策略，当且仅当存在下述有限关系证书。其验证只涉及有限集合。可枚举证书判赢。

证明第一条时，对每个深度枚举定义在所有局部字上的完整确定性动作表，包括未到达的字；本地过去动作可用自身规则重建。安全表截断后仍安全。按延长关系构造有根、有限分支的树。如果每个深度非空，根必有一个子节点具有无界深的后代，重复此选择得到相容的无限表。这一步没有提供可计算的选子节点算法。有限深度失败可以逐表提供一条实际图边序列作为见证，不要求环境存在一条同时击败所有策略的固定轨迹。

第二条的证书是每机的有限记忆 M_i、初始值、输出函数 u_i、更新函数 t_i 和关系 I ⊆ Q × ∏ M_i。I 包含所有可能初始组。每个 (q,m)∈I 和在 u(m) 下每条可能边都必须安全，且 (q', (t_i(m_i,o'_i))_i)∈I。按步归纳即可证明稳定性指标及安全性持续满足，且每个实际后继都持有下一步合法策略。反向取任何安全有限控制器的可达闭环状态作为 I 即得。图上某边是抽象误报时也必须接受该条检查；消除误报依赖细化，不能丢弃不利边。

物理推论比要求公共刷新的版本更广。对每个合法 ε>0，构造 G⁻ 夹在 P_0 与较容易的 P_{−ε} 之间，构造 G⁺ 夹在较难的 P_ε 与 P_0 之间；两图的信息字母均按原网络交付。交错运行所有精度和深度的负证书搜索，以及所有精度和本地记忆大小的正证书搜索。

* 若某个 P_{−δ} 仍不存在任何数学因果赢策，则对任一有效 0<ε≤δ，G⁻ 若赢将推出 P_{−ε} 赢，矛盾。第一条保证找到有限证书，且 P_0 赢本会推出 G⁻ 赢，故判输可靠。
* 若某个 P_δ 有能在共同离散观察字母上实现的有限记忆赢策，且各记忆状态输出有限个真实保持命令，则任一 0<ε≤δ 的 G⁺ 可采用相同有限控制器、按抽象要求就近量化命令，内部更新仍用原命令。这给出第二条证书；图策略在 P_0 上分布式执行。若真实集合有连续观察，必须验证其量化在扩大的观察余量内，并可有限地更新该控制器。

这一区分纠正了把“有限图的完整公共状态算法要求刷新”推广为“两侧的任何终止证书都要求刷新”的推断。无刷新时，严格几何裕量并不足以保证正侧终止，[私有终止反例](private-stop.md) 中甚至存在无法用任何数字控制器实现的数学赢策。上述负侧包含这种信息架构下真正不存在数学策略的实例。两侧之间仍有数学赢、有限状态输的情形。

## 从控制器搜索转到私史关系合并

为使正向搜索利用任务结构，令每机的可能局部历史为一类顶点。一个信息状态 B 是 N 部有限关系族：若隐藏状态 q 和历史组 (v_1,…,v_N) 可共同出现，就加入关系 R_q 的一个元组。每个顶点只属于一架飞机。一个同态 B→C 是各部的局部映射 f_i，每个 R_q 元组必须映到同一 R_q 的元组。若 C 可赢，B 也可赢：各机把自己的初始私史映过去，然后模拟 C 的续策。对每个实际元组，在 C 中存在带同一隐藏节点的像，因此可逐步选择相同环境边与未来观察。映射不提供他机私史。双向同态故保持任意时域的赢性。按元组共现联系顶点的连通分量也可独立求解，每个顶点都唯一指向自己的分量；这不要求线上收到公共广播。

有限关系中可枚举同态与子结构，把 B 换成与其同态等价的最小子结构 C（核），保存 B→C 的见证。C 的每一处方给各自顶点分配本地动作。若有某个元组能走失败边，就删去该处方。否则生成后继关系：新本地顶点为 (v_i,o'_i)，新关系按原图所有合法后继枚举，随后分分量、取核。这个过程没有假设不同顶点具有相同的获胜动作；只在有同态见证时才把策略从较小关系拉回。有限深度归纳给出此计算的精确性：赢家首步在当前核中本就是一份处方，余下树在每个后继分量都赢；反向把各后继续策拉回并与处方拼接。若从初态起全部可达的核同构类型有限，则搜图终止，以最大安全不动点取得永久解。为实际执行，每机保存当前类型及自己的顶点。新观察唯一确定其后继顶点、分量和见证映射的像。由此得到无需刷新私史的有限控制器。输侧由最大不动点删除轮次得到有限时域反证。

一个充分结构条件是所有展开所得分量的关系图（同一元组内顶点两两连边）树深有共同有限上界 d。实际算法无须事先知道 d。证明：选高度 ≤d 的消去森林，每个元组顶点必在同一根叶链上。将元组的关系名、部别和各参数所在祖先深度编码在最深顶点。有限词表和固定 d 只产生有限种标签。在一位父亲的孩子中，若两棵已压缩子树带标签同构，可把一棵折到另一棵并固定其祖先；跨越两个不同子树的非一元元组不存在，故折叠保持全部关系。自底向上压缩，每种子树类型在同父下至多一次；固定高度的类型数由有限标签与上一层类型集的幂集递推给界。根层同样压缩，故核的大小有只依赖 d 与词表的上界。可直接对规范化后的搜索全过程假设该界；若该界只对原始未压缩私史展开成立，核亦可通过选取子结构模拟：核心处方沿回缩拉回，原后继嵌有核心后继（在核心上回缩固定），再取子结构不会增加树深。按步保持此实现。这里的关系图是可能私史间的共现图，与无线通信拓扑的图深不同。

同态压缩与有界树深核定理各自有既有来源，不能把它们列作新的纯博弈定理。本节给出的是保留分布式信息的物理误差夹逼中，哪些可行和不可行证书在取消公共刷新后仍能兑现。图中 q 必须保留估计误差、外系统模式和网络队列所需的全部信息；仅按飞机当前位置合并会破坏同态论证。[分布式博弈的同态抽象](https://lsv.ens-paris-saclay.fr/Publis/PAPERS/PDF/BLP-fsttcs11.pdf) · [有限关系词表下的树深与核](https://users.cs.duke.edu/~br148/hpt-jacm.pdf)
