# tg

本仓库围绕工程及相关数学、算法领域的开放问题开展研究，关注控制理论、优化、计算方法与复杂系统等方向。

## 研究内容

- 从公开文献中识别值得进一步研究的问题。
- 梳理问题定义、已知结果及后续研究进展。
- 探索新的理论结论、算法改进、构造或反例。
- 整理证明、计算实验与可复现的研究材料。

## 目录

- [problems](problems/README.md)：具体问题与研究记录
- [scouting](scouting/README.md)：候选问题与文献线索
- [templates](templates/problem.md)：问题记录模板
- [AGENTS.md](AGENTS.md)：协作与研究规范

各项研究以原始文献和可核验的结果为依据，具体出处及研究进展记录在对应的问题文件中。
