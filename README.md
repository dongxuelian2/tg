# tg / 踢馆

> 教授们留下问题，我们来试着写出答案。

**踢馆**是一个从高校教师及其团队论文中发现开放问题、核查后续文献并尝试给出可检验证明、反例或算法改进的公开研究仓库。

首轮覆盖河北工业大学（HEBUT）、电子科技大学（UESTC）、西北工业大学（NWPU）和南京航空航天大学（NUAA）。国家杰青、长江学者及其团队是优先检索对象，但最终由问题的明确性、可验证性和研究空间决定是否开题。

## 怎么踢

1. **敲门**：追踪论文中的 Problem、Conjecture、Discussion、Conclusion，固定作者、论文、DOI和位置。
2. **查房**：检索正式发表论文、预印本、引用链和作者后续工作，确认仍未解决的部分。
3. **拆招**：写清楚数学定义、量词、已知界和假设；先找可独立研究的特殊情形。
4. **过招**：提出定理、反例、构造或算法；计算观察配独立验证与完整代码。
5. **交卷**：直接在相应问题下提交有实质结论的 PR，不以空泛阶段汇报代替研究。
